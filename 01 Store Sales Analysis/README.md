### **Superstore Sales Analytics**



An end-to-end data analysis project exploring commercial sales transactions, category profitability dynamics, and order metrics using Python and Pandas.



##### 🚀 Key Highlights \& Findings

**Revenue Scale:** Processed over $2.26M in total revenue across 4,922 unique orders.

**Average Order Value (AOV):** Calculated at $459.48, correcting the discrepancy between line-item rows and actual order-level transactions.

**Top Product:** The Canon imageCLASS 2200 Advanced Copier led total product sales with over $61,500.

**Seasonal Spikes:** Q4 periods consistently demonstrated significant revenue peaks compared to earlier quarters.
